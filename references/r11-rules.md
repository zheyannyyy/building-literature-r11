## 0. 正式研究问题（原文不变）

- **RQ1:** What parameter screening or sensitivity analysis methods are commonly used in building simulation studies to identify key design and operational inputs from high-dimensional parameter spaces?

- **RQ2:** How do these key parameters influence the trade-off between building energy use and indoor environmental comfort, and how does their relative importance differ across climates?

- **RQ3:** How can computational approaches that translate screened parameters into energy–comfort co-optimization be systematically classified according to analytical tasks, data regimes, and modelling requirements?

研究范围。审查建筑形体、围护结构及符合 §2.1 条件的环境控制和建筑集成式能源构件。建筑设计固定、只比较独立供能或储能设备配置的研究，按范围外处理。

**术语。**「合格输入」是指属于 §2.1 范围的输入。「合格识别」须满足 §2.2 的四项证据。仅作为固定基准的参数不计为已比较的候选。RQ1 不另设「高维」的数量门槛，仍须比较至少两个不同的合格候选输入或组。英文研究问题中的 high-dimensional 和 operational inputs 留待定稿时复核，筛选时不据此判待核。

## 1. 总体判断逻辑

三个 RQ 共享**参数范围**和**识别证据**，但不要求一篇文章先满足 RQ1 才能审查 RQ2／RQ3。

1. **通用资格。** 按项目现行资格和排除原因定义核对 EX01–EX07。明确不符合时记录对应排除原因。通用资格待核时，可以继续收集 RQ 证据，整篇暂不纳入。

2. **参数与识别。** 先查本篇涉及哪些合格输入，再查提供识别依据的研究。该研究须比较至少两个不同的合格候选。RQ2 和 RQ3 可以引用可追溯的外部识别，本篇可只研究或使用其中一个已识别的输入或组。

3. **分别判断：**RQ1 需要**本篇**识别；RQ2 要求合格参数的定量性能影响与可确定的气候背景；RQ3 要求筛选—优化联系和能耗—舒适共同求优。

4. **汇总整篇：**通用资格符合时，任一 RQ 符合即纳入；三项均明确不符合则排除 **EX08**；无一符合且有待核则整篇待核。若一项符合、另一项待核，整篇仍纳入并保留待核任务。

**逐项审查。** 某个 RQ 缺少决定性证据时，记录要补查的材料并继续判断其他 RQ。RQ1 不符合时，仍可核查 RQ2 或 RQ3 的外部识别来源。RQ3 独立于 RQ2 判断。

## 2. 共同前提：参数范围与识别依据

### 2.1 哪些输入具有资格？

| 编码／类别 | 输入范围 | 参数何时可计为合格输入 |
| --- | --- | --- |
| D 建筑本体设计输入（核心） | 建筑形体与布局、朝向、几何；墙、屋面、地板、门窗及围护结构构造；窗墙比、窗型、玻璃性能、U-value、SHGC、气密性、保温厚度、材料与建筑热质量；固定遮阳构件；可开启窗面积与自然通风开口设计；其他直接描述建筑本体或构件的设计输入。 | 可计入。输入须对应建筑本体、围护结构或建筑构件设计。独立供能／储能设备的类型、面积、容量等配置不属于 D。 |
| **P-V** **被动式自然通风及开窗控制** | 自动开窗温度／风速／CO₂ 等控制阈值、自动开窗开度或比例、自然通风启停规则、夜间自然通风策略及其参数。 | **可计入。** 研究对象须涉及自然通风或被动式降温。纯机械通风量、风机调度和住户开窗行为预测属于范围外输入。 |
| **P-L** **遮阳与自然采光相关控制** | 动态遮阳启闭阈值、百叶角度／控制规则、日光响应调光、与自然采光联动的照明控制参数。 | **可计入。** 控制须直接用于遮阳或日光利用。纯人工照明排班、仅比较照明设备运行效率不满足本类条件。 |
| **P-T** **供暖／****制冷温度设定值（有条件）** | Heating / cooling setpoint、温控死区或与之直接相关的室温控制设定。 | **有条件计入。** 须有原文分析气候或天气条件与温设效应、重要性或选值的关系，见下方示例。 |
| D-I 建筑集成式能源构件（有条件） | 物理上构成建筑屋顶、立面、墙体或其他建筑构件一部分的能源构件；例如与屋面或立面集成的光伏／集热构件、嵌入围护结构的相变材料层。 | 有条件计入。须能从原文确认其物理集成关系，并作为建筑集成设计输入分析。单纯安装在建筑旁、接入建筑能源系统或独立配置的设备不属于 D-I。 |
| S 独立能源设备／系统配置（范围外） | 独立太阳能集热器面积／容量、独立光伏容量、蓄热水箱或热化学储能的类型／容积、热泵／锅炉／冷机类型或容量、HVAC 系统配置、换热器、泵、管路及储能反应器参数等。 | 不计为合格输入，也不计入 n／k／r／o。若建筑设计固定且全文只比较 S 类配置，通用资格符合时按 EX08 排除。若同时分析合格建筑设计输入，仍按其他条款审查该研究；S 类变量只作辅助／系统输入记录。 |

归类示例。可开启窗面积是建筑设计输入，归 D；自动开窗的温度阈值是控制输入，归 P-V。固定遮阳板的挑出长度归 D，运行中调节百叶角度的规则归 P-L。HVAC 或储能设备类型、面积、容量等若作为独立系统配置比较，归 S；只有物理上构成建筑构件并作为建筑集成设计分析的能源构件，才可进一步审查 D-I。

**P-T** **的操作性核查。** 从原文查找气候或天气如何关联温度设定值的性能效应、相对重要性或选值。可比较不同气候区，也可比较同一城市的季节或明确的天气情景。来自同一份天气文件的情景也可用于分析。只报告地点，或只用当地天气数据给出一个总体最优设定值，证据不足。RQ2 的气候背景另行判断。

**P-T** **示例。** 同一城市在普通夏季天气和热浪情景下分别比较 24°C、25°C 和 26°C。若 26°C 在普通天气下满足舒适约束，在热浪期间却超过过热时长上限，温设可计为合格输入。若论文只用该市典型气象年比较这三个温设并选出总体最优值，则温设不能独立计入。

不作为独立合格输入：机械新风／送风量、机械通风方式和送风温度、HVAC／AHU 启停排班、冷冻水／热水设定、设备运行调度与纯实时控制算法；独立供能／储能设备及系统配置（S 类）；人员密度和占用时程、手动操作行为、服装热阻／代谢率；气候／天气作为外部边界、纯模型校准因子、算法超参数、财务权重、设备故障标签及仅用于预测人员行为的特征。仅讨论施工湿安全、构件耐久性或孤立材料物性而无相关建筑使用性能的研究不属于此范围。

**混合研究的处理（重要）：**

- 先标出合格输入。研究同时比较独立系统配置与合格建筑输入时，凭合格输入的证据分别审查各 RQ。

- 未达到 P-T 气候关联要求的温设可作辅助运行变量记录。

- 按变量实际用途归类。自动开窗阈值归 P-V，日光响应调光归 P-L，独立 HVAC、供能或储能设备配置归 S。

- 多个输入共同变化时，将结果记在实际变化的参数组名下。只有原文能区分合格输入或合格输入组的作用时，才将结果归给对应的输入或组。至少两个候选的要求只计合格输入或合格输入组。

### 2.2 合格识别必须具备的四项证据

**识别可以由本篇或可追溯外部研究提供**；但 RQ1 必须由本篇完成（§3）。

| **证据** | **最低核查要求** |
| --- | --- |
| **①** **有候选** | 在实施识别的研究中，至少比较**两个不同的合格候选输入或合格输入组**；同一输入的多个取值不算不同输入。 |
| **②** **有比较** | 交代比较哪些输入／组、如何变化，以及重要的范围或条件。 |
| **③** **有数值** | 有能够对应这些输入／组的建筑使用性能数值或明确的重要性指标。 |
| **④** **有结论** | 定位作者对输入或组的重要性判断，例如排序，或指出哪项输入敏感、影响较弱、可忽略或应保留。只有图表数值而无作者判断时，筛选者不自行判定重要性。 |

**如何使用数值。** 某个温设的最优值、节能百分比、方案评分、Pareto 点分布或得热份额，单独都不足以证明参数识别。敏感性指数可作为本节的重要性数值证据。用于 RQ2 时，还须按 §4 条件②核查该输入对应的定量性能结果。

**方法不限定名称：**Morris、Sobol、FAST、OAT／OFAT、回归、LASSO、RFE、SHAP、代理模型解释、优化后重要性分析等均可，关键是四项证据完整。不要求完整排序、独立敏感性章节或实际删减参数。机器学习输入须映射到合格建筑性能输入，特征重要性不能直接解释为因果效应。

**组级识别。** 记录组内有哪些输入、该组如何变化、组外是否同时变化、整组的数值结果及作者判断。整组的重要性结论只归给该组。

### 2.3 外部识别如何核实？

**外部识别来源。** 找到具体文献、该文献实际识别的合格输入或组，以及它与本篇输入的对应依据。本篇已提供足够证据时可据此记录，关键证据不足时查外部来源。仅称「参考文献选择参数」而未说明识别结果，证据不足。必要时注明两项研究的建筑、气候和参数范围差异。

**RQ2** **与** **RQ3** **的对应要求。** RQ2 核对外部识别对象是否对应本篇定量结果所分析的输入或组。记录组成员、比较条件及同时变化的其他输入。两项研究的具体取值可以不同。外部识别只覆盖整包方案的一部分时，须有可归给这部分输入的定量结果。RQ3 核对本篇据哪条外部识别结论确定了哪项求优设置，见 §5-B。

**RQ1** **例外：**只引用外部筛选，不能代替本篇开展识别；若本篇另有合格识别仍可审查 RQ1。

## 3. RQ1｜本篇如何识别关键输入？

**符合条件。** 本篇使用建筑模拟或建筑性能模型，实际开展筛选、敏感性分析或其他能判断输入重要性的比较，满足 §2.2 四项证据，并能定位合格输入或组的识别结果。

**性能范围。** 识别须对应至少一项建筑能耗、供暖或制冷负荷、或室内环境性能。例如，院落朝向可归 D。若论文只识别了朝向对室外风速的影响，而室内采光来自无法区分朝向作用的整方案对照，则 RQ1 不符合。室外结果可留作背景，其他 RQ 仍分别核查。

- 本篇可先按文献或经验预选输入。识别阶段须比较至少两个不同的合格输入或组，最终可以只识别出一个重要输入或组。

- 同时研究能耗和舒适、比较多种气候、完整排序及实际删减变量均不是 RQ1 的必要条件。

- **不符合：**只比较单一参数不同取值挑最优、只选最优方案、仅引用前人结论、只有财务敏感性、只调校模型或优化预测精度而没有合格建筑输入的重要性结论。

- **待核：**本篇是否真正识别、合格候选有哪些、指标或作者结论能否对应等决定性信息尚缺。

## 4. RQ2｜关键输入对能耗或舒适的影响与气候

**单篇** **RQ2** **的三项必要条件：**

| **条件** | **最低要求** |
| --- | --- |
| **①** **已识别的合格输入** | 本篇或可追溯外部来源满足 §2.2，识别对象对应本篇被分析的合格 D／P-V／P-L／P-T／D-I 输入或组。 |
| **②** **定量性能影响** | 已识别的输入或组至少有一项可对应、可定位和可复核的建筑用能、供暖或制冷负荷，或室内舒适定量结果。不能只有基准方案值。 |
| **③** **气候背景可确定** | 可从正文／图表／附录／可靠研究设定中提取与结果对应的研究城市、气候分区或天气／气候条件。 |

**条件****②****的取证。** 可记录原文数值、按同一对照计算的变化量、从有明确刻度的图中估读的数值或区间，以及定义和比较范围明确的单项归一化指标。记录单位或无量纲、原文位置，以及适用的估读或计算方法。仅有变化方向、方案名次或跨多项性能的综合得分，证据不足。例如，外遮阳对照的归一化过热表现由低于 0.5 变为高于 0.5，可记录该无量纲区间。换算过热小时须有原文提供的换算依据。采用外部识别时按 §2.3 核对输入与结果的对应关系。

**单篇判定。** 满足上表三项即符合 RQ2。单篇可以只有一个气候背景，也可以只报告能耗或室内舒适中的一类。能耗可为总能耗、供暖、制冷、照明等，条件②也接受供暖或制冷负荷。室内舒适可用热、视觉、声、空气品质或综合室内环境指标表示。室外舒适与施工期风险不属于室内舒适。

**综述汇总。** 分别回答能耗与室内舒适之间有何权衡，以及参数的相对重要性如何随气候变化。单篇论文可以只为其中一部分提供证据。

- 单性能研究只用于相应性能的参数效应，不据此断言双性能权衡。

- 权衡／协同优先依据**同案例、同参数变化、同基准**的能耗与舒适成对数值；跨气候重要性比较需检查候选范围、参数变化区间、建筑情景、运行设定和指标的一致性。

- 对包含 setpoint 的跨气候研究，记录各气候的温设是固定值、变化范围还是优化结果；气候与设定温度一起改变而未区分作用时，不可直接把重要性差异归因于气候。

- **气候信息对应到结果。** 如果论文只研究一个明确的城市，研究城市可用于满足条件③。如果有多个城市或天气情景，须确定所提取的结果对应哪一个。温设是否计为合格输入，另按 §2.1 判断。

**不符合：**没有合格识别来源；定量结果未满足本节条件②；必要核查后仍无法确定气候背景（记录 NR）。气候缺失只影响 RQ2，不否定已符合的 RQ1 或 RQ3。

**待核：**上述决定性证据可能在尚未核查的正文、附录、天气文件或外部来源中，须列明缺口。**不以缺少跨气候比较或仅单性能为待核理由。**

## 5. RQ3｜识别结果怎样进入能耗—舒适协同优化？

**三段证据链必须全部成立：**

| **段落** | **成立所需证据** | **典型不符合** |
| --- | --- | --- |
| **A** **识别来源** | 本篇或具体外部研究按 §2.2 识别合格 D／P-V／P-L／P-T／D-I 输入或组。 | 仅经验选取、笼统声称重要，没有实际识别依据。 |
| **B** **传递到优化** | 指出 A 段哪条识别结论实际决定或改变了优化变量、范围、分组、搜索空间、参数化方式或代理模型输入，并定位实施位置。 | 筛选与优化虽同篇出现但互不相干，或识别只用于事后解释。 |
| **C** **双性能求优** | 有明确的候选空间和计算搜索或选择规则。能耗与室内舒适可均为目标或评分项。若只有一项作为目标或评分项，另一项至少须作为实际限制候选方案的约束。 | 仅求优后才检查舒适；仅人工评价几套完整预设方案；成本为唯一目标、能耗与舒适均只作固定达标约束。 |

**B** **段示例。** 作者比较保温厚度与窗墙比，识别出窗墙比影响较大，并明确据此将它纳入后续搜索，B 段成立。A 段须比较至少两个合格候选，B 段可只使用其中一条识别结论。不要求删减参数。若两步只是使用了同一组变量，应核查原文是否说明识别如何影响求优设置。优化完成后的重要性分析若用于后续求优，也可计入 B 段。

**方案枚举和多准则决策分析（****MCDA****）。** 核查候选方案如何形成、计算选择规则是什么、识别结果如何影响设置，以及能耗和舒适如何参与决策。仅报告预设方案的评分和名次，无法确认完整的 A、B、C 证据。可同时记录辅助机械运行或温设变量，其参数资格仍按 §2.1 判断。

**C** **段示例。** 在符合过热时长上限的方案中选能耗最低者，C 成立。先选出能耗最低者，事后才报告过热时长，C 不成立。成本是唯一目标，且能耗和舒适仅作为固定达标约束时，C 不成立。A、B、C 均成立才符合 RQ3。

**待核：**识别来源、传递位置、两项性能的目标／约束是否在求优过程中执行等关键证据暂缺。纳入后进一步编码**分析****任务／****数据****条件／****建模要求**；这几项分类资料未报告但不影响纳排时记 NR。

## 6. 分项判断与整篇结论

| **通用资格** | **三项** **RQ** **状态** | **整篇处理** |
| --- | --- | --- |
| 明确不符合 | 不需为纳入目的继续审 RQ | 排除 **EX01–EX07**，记录原因 |
| 待核 | 可继续搜集 RQ 证据，但不能正式纳入 | **整篇待核：通用资格** |
| 符合 | 至少一个 RQ 符合，其余可不符合／待核 | **纳入**，保留待核事项 |
| 符合 | 全部 RQ 明确不符合 | 排除 **EX08** |
| 符合 | 没有 RQ 符合，但至少一个待核 | **整篇待核**，定向补查 |

三个 RQ 分别记「符合」「不符合」或「待核」。决定性材料尚未核查、可能改变裁决时，记「待核」并列出要补查的内容。必要核查后确认缺少证据，或已有证据明确未达到要求时，记「不符合」。例如，附录尚未取得且可能含有对照数值，可记 RQ2 待核。查完材料仍只有变化方向，则 RQ2 的条件②不符合。会议和期刊论文使用同一标准。

## 7. 数据提取和团队复核

### 7.1 四个数量 n／k／r／o 与参数分类

合格输入计入 n／k／r／o。将 S 类和其他辅助输入单列，并保留原文全部候选数 n\_all。

| **字段** | **含义** |
| --- | --- |
| **n** **候选数** | 同一次识别分析中，实际参加比较的合格候选输入或输入组数量 |
| **k** **重要数** | 作者识别为重要的合格输入／组数量 |
| **r** **保留数** | 识别后实际保留、进入下一阶段的合格输入／组数量 |
| **o** **求优变量数** | 最终进入计算求优的独立合格输入／组数量 |

另记：原文所有候选数 n\_all，以及合格输入的 D／P-V／P-L／P-T／D-I 分类数量；非合格 setpoint、机械运行及人员变量记为辅助／背景输入，不计入 n/k/r/o。如原文报告所有优化变量总数，可另记 o\_all，不与 o 混用。

**计数。** 一个输入的多个取值只计一个，例如三种 HVAC 系统类型属于同一个「系统类型」输入。合格输入作为一组共同变化且不能单独设置时，按一组计并列出成员。可独立变化时分别计。模拟次数、方案数、天气数、取值档数、重复派生量、交互项及主成分不重复计入。不同分析分开记录。**缺项。** NA 表示不适用。NR 表示适用，但核查后仍未报告。尚待核查且可能影响裁决时，记录「待核」及缺口。n、k、r、o 分别记录。

**混合计数示例：**某研究实际筛选 3 个围护结构设计输入和 2 个温度 setpoint。如果 setpoint 未满足 §2.1 的独立气候关联条件，记 n\_all=5，n=3（D=3，P-T=0）；仍保留原文 5 项的整体重要性分析范围及重要性指标，**不擅自重算敏感性占比或将原始排名当成仅设计输入的独立分析结果**。若温设满足 P-T 条件，才将对应设定值计入 n。

### 7.2 RQ2 六项记录（气候背景是必要条件）

| **字段** | **记录方式** |
| --- | --- |
| 能耗类型 | 总／供暖／制冷／照明／其他／未研究，可多选 |
| 舒适类型 | 热／视觉／声／空气品质／综合／未研究，可多选 |
| 具体指标 | 记录指标名称、数值或变化量、单位或无量纲，以及原文位置。 |
| 性能覆盖 | 仅能耗／仅舒适／能耗＋舒适 |
| 双性能是否配对 | 是否来自**同案例、同一次合格参数变化、同基准**；是／否／待核／NA |
| **气候背景（必要****）** | 城市／气候区／天气条件及原文位置；**可确定****→****符合本项，核实后无法确定****→****NR** **且** **RQ2** **不符合，关键材料未查****→RQ2** **待核** |

每条 RQ2 定量结果均记录指标、对应输入或组、比较条件（如适用）、数值或变化量、单位及原文位置。能耗和舒适来自同一案例、同一次输入变化、同一基准时标为配对。只有一类性能时记 NA。两类性能无法配对时，可分别记录，用于各自的参数效应分析。除气候背景外，表中的描述字段不另设单篇纳排门槛。跨气候比较另记参数范围、建筑原型、运行条件和温设是固定值、变化范围还是求优结果。

### 7.3 RQ3 原文证据、筛选记录与复核

**RQ3** **按** **A****、****B****、****C** **分别定位证据。**

- **A** **段。** 记录本篇或外部来源、识别出的合格输入或组，以及识别结论的位置。

- **B** **段。** 记录 A 段哪条识别结论决定了哪个变量、范围、分组、搜索空间、参数化设置或代理模型输入，并注明实施位置。

- **C** **段。** 对能耗、舒适分别记录其角色：目标、评分项、求优中执行的约束、仅事后评价或未报告。注明目标函数、评分规则或约束的原文位置。

**最低记录字段。** 文献 ID｜通用资格｜合格输入类别与辅助输入｜n\_all、n/k/r/o（有报告时记 o\_all）｜识别方法和四项证据的位置｜RQ1/RQ2/RQ3 裁决｜RQ2 六项及定量结果｜外部识别来源｜RQ3 A/B/C 证据｜待核缺口｜复核人、日期和规则版本。

两人独立筛选并保留各自原判。分歧依据全文证据讨论，票数和 AI 输出不能直接决定裁决。改判时记录旧判、新判、条款、证据位置和确认人。正文与图表的数值或单位冲突时定向核查。规则锁定后，回查受规则调整影响的文献，并更新 PRISMA 数量。
