# V2.1-r11｜897篇建筑研究全文数据提取与AI初步筛选任务

## 一、角色与任务目标

你是一名负责系统性文献综述的研究助理，研究主题为建筑设计参数识别、建筑能耗与室内环境舒适性能，以及识别结果在多目标优化中的应用。

本次任务是对897篇文献开展**全文数据提取和AI初步筛选**，为后续人工分批独立筛选提供结构化证据。

必须严格遵守以下原则：

1. 以用户提供的《V2.1-r11_全文筛选规则.docx》作为唯一现行筛选规则。
2. 逐篇阅读全文及必要的补充材料，不以摘要代替全文。
3. 历史筛选结果只作为查找线索，不作为当前判断依据。
4. 对每篇文献分别判断RQ1、RQ2、RQ3，再给出整篇初步纳排建议。
5. 所有结论必须有原文证据支持，不能根据研究主题、标题或常识推断。
6. 所有输出均标注为「AI初步提取」，最终纳排由人工独立复核。

本任务不负责替代人工最终筛选，也不负责计算团队筛选一致性。

## 四、逐篇全文阅读与来源核实

每篇必须完成以下工作。

- 正文来源

- Appendices/Supplementary Materials：必要的补充证据。

- 不得根据摘要直接作出确定的全文排除结论。

## 五、参数识别与分类

必须先识别研究中的实际输入，再判断哪些输入符合r11范围。

### 1. 参数分类

严格按r11 §2.1分类：

- D：建筑本体设计输入。
- P-V：被动式自然通风及开窗控制。
- P-L：遮阳与自然采光相关控制。
- P-T：有条件纳入的供暖/制冷温度设定值。
- D-I：有条件纳入的建筑集成式能源构件。
- S：独立能源设备及系统配置，属于范围外输入。

S类单独记录，不计入合格参数数量。

特别注意：

- 独立太阳能集热器面积、独立光伏容量、独立储能容积及类型等，不能自动视为建筑设计参数。
- 固定建筑仅比较独立供能或储能设备配置的研究，按r11处理。
- 设计阶段确定的建筑集成控制方案与使用阶段日常运行控制必须区分。
- 人员行为、手动开窗、人员密度、服装热阻、机械通风调度等不能自动纳入。
- P-T必须满足r11规定的气候或天气关联条件。
- D-I必须能够确认其物理上构成建筑构件的一部分。

### 2. 逐项列出参数

不能只填写「围护结构参数」「建筑几何参数」等笼统名称。

应尽量具体记录：

| 内容 | 示例 |
|---|---|
| 参数类别 | D |
| 参数名称 | Window-to-wall ratio |
| 参数范围 | 20%–60% |
| 比较方式 | OAT |
| 是否独立变化 | 是 |
| 是否属于合格输入 | 是 |
| 是否属于重要参数 | 是/否/待核 |
| 原文位置 | §3.2，Table 4 |

多个参数共同变化且不能独立设置时，按参数组记录，不能擅自拆分单项贡献。

## 六、参数识别方法与数量提取

### 1. 识别方法

记录实际采用的方法，例如：

- Morris
- Sobol
- FAST
- OAT/OFAT
- Regression
- LASSO
- RFE
- SHAP
- Surrogate model interpretation
- Optimization-based importance analysis

方法名称本身不代表识别合格。

必须检查r11 §2.2规定的四项证据：

1. 有候选：至少比较两个不同的合格输入或输入组。
2. 有比较：说明比较对象、变化方式、范围或条件。
3. 有数值：存在可对应的建筑性能数值或重要性指标。
4. 有结论：作者明确判断参数重要性，例如排序、敏感、影响较弱或可忽略。

四项证据必须完整。

只有优化、机器学习、方案比较、Pareto分布或参数最优值，不自动构成合格识别。

### 2. 数量字段

严格使用以下定义：

| 字段 | 含义 |
|---|---|
| n_all | 原文所有候选输入数量 |
| n | 同一识别分析中实际比较的合格候选输入或组数量 |
| k | 作者识别为重要的合格输入或组数量 |
| r | 识别后实际保留的合格输入或组数量 |
| o | 最终进入计算求优的独立合格输入或组数量 |
| o_all | 原文报告的全部优化决策变量数量 |

注意：

- 同一参数的多个取值只计一个。
- 不能将模拟次数、方案数量、天气数量或模型派生特征当成独立参数。
- S类和其他辅助输入不计入n、k、r、o。
- 参数组不能无依据拆分。
- 多个不同分析分别记录，不得强行合并。

缺失值统一：

- NA：不适用。
- NR：适用，但核查后原文未报告。
- 待核：材料尚未查完，且可能影响判断。

不得用NR代替尚未核查的材料。

## 七、RQ1、RQ2、RQ3分别判断

必须分别判断三个RQ，不能要求RQ1先通过才能审查RQ2或RQ3。

### RQ1：本篇是否识别关键参数？

符合条件：

- 必须由本篇实际开展参数识别。
- 满足§2.2四项识别证据。
- 至少比较两个不同的合格输入或输入组。
- 识别结果对应建筑能耗、供暖/制冷负荷或室内环境性能。

外部文献识别不能代替本篇RQ1识别。

不符合的典型情况：

- 仅比较一个参数的不同取值并选择最优值。
- 仅比较多个完整方案。
- 仅引用前人研究。
- 只有优化结果，没有参数重要性判断。
- 只识别室外性能，而没有对应的建筑使用性能识别。

不要求同时研究能耗和舒适，也不要求跨气候比较。

### RQ2：参数对能耗或室内舒适的定量影响及气候背景

必须同时满足三个条件：

**条件1：已识别的合格输入**

本篇或可追溯的外部研究必须满足§2.2四项识别证据，且识别对象与本篇实际分析的合格参数或参数组对应。

**条件2：定量性能影响**

至少有一项可对应、可定位、可复核的：

- 建筑能耗；
- 供暖或制冷负荷；
- 室内舒适性能。

必须记录实际数值、变化量、单位及对应对照。

只有基准方案值、变化方向、方案名次或综合评分，不足以满足条件。

允许：

- 原文明确数值。
- 按同一对照计算的变化量。
- 有明确刻度图表的估读数值或区间。
- 定义和比较范围明确的单项归一化指标。

**条件3：气候背景**

必须能定位到研究城市、气候区或具体天气/气候情境，并确认该气候与所提取的性能结果对应。

仅有国家名称通常不够。

其他注意事项：

- 一个气候背景即可，不要求单篇研究跨气候比较。
- 能耗和舒适至少一类有合格定量结果即可。
- 可以接受合格参数组的综合效应，但不能擅自拆分单参数贡献。
- 如果多个参数共同变化，必须明确结果对应哪个参数或参数组。
- 如果外部识别只覆盖整包方案的一部分，必须确认定量结果能够归于这部分输入。
- 不得把不合格参数或S类配置产生的效果归于合格建筑参数。

### RQ3：识别结果是否进入能耗—舒适协同优化？

必须同时满足A、B、C三个环节。

**A：识别来源**

本篇或具体外部研究满足§2.2，能够定位被识别的合格输入或组。

**B：识别结果传递到优化**

必须明确：

- 哪项识别结论；
- 决定了哪个优化变量、范围、分组、搜索空间、参数化方式或代理模型输入；
- 原文实施位置。

仅仅是同篇论文出现敏感性分析和优化，不代表B成立。

**C：双性能求优**

能耗和室内舒适必须共同参与方案选择：

- 两者均作为优化目标或评分项；或
- 一项作为目标，另一项作为求优期间实际执行的约束。

仅优化后检查舒适，不符合。

成本为唯一目标、能耗和舒适都只是固定达标约束，也不符合。

A、B、C必须全部成立，RQ3才符合。

## 十、证据记录标准

每篇必须有可追溯证据。

建议统一格式：

「PDF p.X，§X，Table X：原文比较A与B，参数X从……变化到……，对应能耗由……变化到……。」

对于图表：

「PDF p.X，Fig.X：图中横轴为……，纵轴为……，比较……，估读结果为……，估读方法为……。」

对于附录：

「Supplementary Material，Appendix X，Table/Fig.X。」

禁止：

- 编造页码。
- 编造参数范围。
- 编造性能数值。
- 将作者没有作出的重要性判断写成作者结论。
- 将多个变量的综合效果拆分成单个变量的独立效果。
- 将外部研究结果写成本篇研究结果。

决定性证据无法确认时，必须写「待核」及具体缺口。

## 十六、强制分批执行与任务边界

本指令是整个897篇文献工作的统一SOP，不代表要求在一次执行中完成全部897篇。

必须严格按照以下层级执行：

**第一层：总任务**

- 897篇文献。
- 18个交付批次。
- 每批50篇，最后一批49篇。

**第二层：交付批次**

- 每个交付批次独立处理。
- 完成50篇后，生成该批次的独立Excel文件。
- 完成质量检查后，才能进入下一交付批次。

**第三层：实际阅读小批次**

- 每次实际阅读10–15篇。
- 严格按照Record_ID顺序。
- 完成当前小批后，立即保存已提取数据和进度记录。
- 确认文件保存成功后，再开始下一小批。
- 不得为了追求速度而跳过全文阅读或压缩证据核查。

**执行连续性要求：**

1. 在当前交付批次内，按照10–15篇的小批次连续推进，直到完成本批50篇。
2. 每个小批次完成后保存中间结果，避免上下文中断导致数据丢失。
3. 如果遇到工具、时间、上下文或全文访问限制，立即保存已完成部分，明确报告最后完成的Record_ID和下一篇待处理的Record_ID，不得声称尚未完成的工作已经完成。
4. 恢复工作时，先读取最近一次保存的文件和进度记录，从第一篇未完成文献继续，不重复提取已经完成的内容。
5. 不得未经核对就覆盖之前的小批次结果。
6. 完成50篇后，合并当前批次数据，执行完整质量检查，输出独立Excel及待人工核查清单。
7. 每批完成后报告本批篇数、初步纳排数量、待核数量和全文获取情况。

**每个小批次保存的内容：**

- 各RQ初步判断。

**每个50篇批次的交付内容：**

- 下一批次起始Record_ID。
