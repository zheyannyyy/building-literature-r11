# 建筑文献全文初筛 V2.1-r11

按项目指定的 V2.1-r11 正式规则裁决。[r11 规则](../../../references/r11-rules.md) 收录筛选条款。以用户指定的主工作簿确定 Record_ID、批次和交付字段。通用资格须依据项目现行 EX01–EX07 定义。执行时读取 [数据格式和命令](../../../references/workflow.md)，需要核对原分工或交付细节时查阅 [SOP](../../../references/SOP.md)。

1. **建立批次计划。** 用 `r11.py plan` 读取 `03_说明` 和已交付文件，确定第一个未完成的 Record_ID。按 10–15 篇为一小批推进，优先使用已取得且身份匹配的全文，缺少材料时记录需要补查的来源。
2. **逐篇提取。** 用 `extract_paper.py` 为下一篇生成题录草稿。核对题名、DOI、全文和必要附录。涉及参数范围、敏感性或性能变化的图表时，查看 PDF 原页的坐标轴、单位、图例和对照。记录页码、图表编号及估读方法。历史记录和文字提取可用于定位证据。
3. **按规则裁决。** 分别判断通用资格、RQ1、RQ2、RQ3。RQ1 对照本篇的四项识别证据。RQ2 把参数或参数组、气候、数值、单位、适用的对照和原文位置连在同一条结果中。RQ3 记录 A 段的识别结论、B 段如何将该结论用于求优设置，以及 C 段两项性能在求优中的角色。用 NA、NR、待核分别标记不适用、核查后未报告、决定性证据待查。
4. **保存和交付。** 用 `r11.py save` 保存逐篇证据 JSON。每个小批结束时可用 `update_excel.py export --snapshot` 保存进度。按 03 的实际批次完成后，用 `validate_batch.py` 检查批次，再导出工作簿及待核清单。合并用 `update_excel.py merge`，结果写入总表副本。中断后用 `plan` 恢复，待核事项进入补证清单。AI 初步判断供人工独立复核。

## 与 `$literature-research`（可选）的协作

- 先用本项目 `plan` 确定 Record_ID。已有匹配全文时可直接阅读。需要获取全文、核验 PDF 或定位片段且已安装第三方 skill 时，查阅 [双 Skill 协作指南](../../../references/literature-research-integration.md)。
- 用 Excel 的题名和 DOI 核对 PDF 身份。第三方索引提供定位线索。回到正文、图表和附录原页核实，再把来源与证据写入该 Record_ID 的 JSON。决定性材料待查时，记录具体缺口。
- 两个工具目前通过 PDF 和原文位置交接。RQ 判断、逐篇保存和 Excel 导出都继续按本工作流执行。
